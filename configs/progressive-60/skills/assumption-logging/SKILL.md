---
name: assumption-logging
description: Rule for recording assumptions in plans and analyses. Use when producing an estimate, plan, model, or recommendation that rests on things not yet known.
---

Assumptions go in the document, not in the author's head. Each one names what would falsify it.

An assumption nobody can check is not documented, it is decorated. If falsification is impossible, say that plainly — it changes how much weight the conclusion can bear.
