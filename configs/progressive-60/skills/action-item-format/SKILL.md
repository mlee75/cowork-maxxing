---
name: action-item-format
description: House format for action items in any document. Use when producing a task list, action list, or follow-ups section.
---

An action item is owner, verb, object, date. "Look into the pricing thing" is not an action item, and "team" is not an owner.

An item with no date is not tracked; either give it one or record it as a decision not to act.
