---
id: security-incident-comms
tier: 3
description: Rule for communicating about security incidents to customers and externally. Use when drafting any external message about a breach, vulnerability, or security event.
---

State what is known, what is not yet known, and when the next update will come. A first message that waits for complete information arrives after the customer has heard elsewhere.

Do not characterise impact before the investigation supports it. Revising "no customer data was affected" is far more damaging than never having said it.
